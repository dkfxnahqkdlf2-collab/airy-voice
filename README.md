# 🎙️ Shorts Voice Studio Pro (쇼츠 보이스 & 캡션 스튜디오)

> **대본만 넣으면 1초 만에 쇼츠 전용 고음질 내레이션(.mp3)과 캡컷 1줄 싱크 자막(.srt)을 동시 완성하는 올인원 스튜디오**

---

## 💻 1. 컴퓨터 사양 및 그래픽카드 조건 (필독!)

본 프로그램은 **구독자 여러분의 PC 환경에 맞춰 2가지 모드로 동작**하도록 설계되었습니다.

| 구분 | ⚡ Edge-TTS 초고속 모드 (기본/추천) | 🤖 AI 내 목소리 복제 (Voice Clone) |
| :--- | :--- | :--- |
| **외장 그래픽카드** | **전혀 필요 없음 (사무용 노트북/일반 PC 100% 가능)** | **NVIDIA 외장 그래픽카드 필수 (CUDA 지원)** |
| **권장 GPU 사양** | 내장 그래픽(인텔 UHD / AMD 라데온) 가능 | RTX 2060, RTX 3060 이상 (VRAM 6GB 이상) |
| **생성 속도** | **1~2초 만에 즉시 완성 (초고속)** | 문장당 약 5~8초 소요 (로컬 AI 신경망 연산) |
| **비용/제한** | **100% 완전 무료, 무제한 생성** | 100% 완전 무료, 로컬 GPU 연산 |
| **추천 대상** | **모든 사용자, 빠르고 또렷한 지상파 톤 쇼츠 제작** | 내 오리지널 목소리 톤으로 채널을 브랜딩할 분 |

> 💡 **외장 그래픽카드가 없어도 실망하지 마세요!**  
> 기본 제공되는 **Edge-TTS 모드**만으로도 지상파 다큐멘터리 아나운서처럼 힘차고 또렷한 고품질 쇼츠 음성(인준, 선희, 현수, 미국 1위 성우 Christopher 등)을 1초 만에 무료로 만드실 수 있습니다!

## 🚀 2. 초간단 3단계 설치 & 실행 방법

### [사전 준비] Python 설치
1. 컴퓨터에 **Python 3.10 ~ 3.12**가 설치되어 있어야 합니다.
2. 파이썬 설치 파일 실행 시, 맨 아래 **`☑️ Add python.exe to PATH`** 체크박스를 반드시 체크하고 설치해 주세요.

---

### [원클릭 설치 및 실행 순서]

1. **1단계: 필수 라이브러리 자동 설치**
   * 폴더 안의 **`설치_및_환경설정.bat`** 파일을 더블클릭합니다.
   * 필요한 파이썬 패키지들이 1분 만에 자동으로 설치됩니다.

2. **2단계: 바탕화면 바로가기 생성**
   * 폴더 안의 **`바탕화면_바로가기_만들기.bat`** 파일을 더블클릭합니다.
   * 바탕화면에 **전용 스튜디오 마이크 아이콘**이 적용된 바로가기가 즉시 생성됩니다!

3. **3단계: 프로그램 실행**
   * 바탕화면의 **`쇼츠 보이스 & 캡션 스튜디오`** 아이콘을 더블클릭합니다.
   * 인터넷 브라우저 창이 자동으로 열리며 프로그램이 시작됩니다! (포트: `8502`)

## ✨ 3. 핵심 기능 둘러보기

### ① 대본 100% 자동 클리닝 (노가다 제로)
대본에 `[제목]`, `(화면: 00:00)`, `[소요시간]`, `(효과음)` 등의 연출 지시문이 섞여 있어도 **성우가 읽어야 할 순수 대사만 AI가 100% 자동 정제**하여 읽어줍니다.

### ② 쇼츠 성우 톤 자동 마스터링 (지상파 아나운서 톤)
유튜브 쇼츠에서 시청자의 귀를 사로잡도록 **쇼츠 전용 오디오 마스터링 프리셋**이 기본 적용됩니다:
* **무음 0.12초 자동 압축** (말 사이의 불필요한 침묵 제거)
* **1.15배속 템포 업** (루즈하지 않은 박진감 넘치는 텐션)
* **묵직한 중저음 피치 보정 (-0.9st)** (신뢰감 넘치는 다큐 성우 톤)
* **+3.5dB 펀치감 컴프레서** (모바일 스피커에서도 0.1초 만에 꽂히는 음압)

### ③ 캡컷(CapCut) 0.1초 싱크 자막 (.srt)
음성이 생성됨과 동시에 **캡컷 1줄 팝업 규격에 100% 최적화된 `.srt` 자막 파일**이 자동 생성됩니다.
* 캡컷 PC 상단 **[텍스트] ➔ [로컬 자막] ➔ [가져오기]**에서 파일만 선택하면 나레이션 박자에 맞춰 자막이 1초 만에 깔끔하게 배치됩니다.

### ④ 🇺🇸 영어(글로벌) 쇼츠 모드 지원
상단에서 **[🇺🇸 영어 모드]**를 선택하시면, 해외 밀리터리/VS 쇼츠 채널 부동의 1위 성우인 **Christopher** 미국 원어민 성우와 영어 전용 자막 분할 알고리즘이 가동됩니다.
